# STMPCK development builds

[Download the latest Android APK](https://raw.githubusercontent.com/cjtrowbridge/stmpck-builds/main/latest.apk).

Open the download on your Android phone to install it. Android may ask you to allow installation from your browser. For later builds, STMPCK checks silently when it opens; you can also use **Settings → Check for update**. Installation always needs confirmation. Matching builds and startup network failures produce no prompt, and ordinary play works offline.

This is the arm64 development app, package `dev.cjtrowbridge.stmpck.debug`, currently version **0.3-dev (3)**. Updates retain the original STMPCK signing identity and preserve app data when upgrading a compatible installation. Do not uninstall an existing app to work around a signing mismatch.

This repository contains only development APKs, checksums and build metadata. Application source and signing keys are not published here. See [build metadata](build.json) and [SHA-256 checksum](latest.apk.sha256). This is not an app-store release.
